Public API

Free, read-only JSON for prediction market traders on Polymarket and Kalshi. No API key needed, and it works from the browser (CORS enabled). Leaderboards update every few minutes.

Base URL: https://predicting.top · Please credit predicting.top and link back when you display the data.

Example

JavaScript
// Top 10 Kalshi traders this month
const res = await fetch("https://predicting.top/api/kalshi-leaderboard?period=30d&limit=10");
const { traders } = await res.json();

traders.forEach(t => console.log(t.rank, t.name, t.pnl));

Endpoints

GET/api/leaderboard

Full cross-platform leaderboard (Polymarket, Kalshi, Myriad), ranked by P&L for the period.

Params: period=1d|7d|30d|90d|ytd|all

Try: /api/leaderboard?period=7d

Fields: rank, name, platform, wallet, kalshi_username, pfp, stats, allTimePnl, smart_score, twitter, roi, sports_share, day_mover

GET/api/embed/leaderboard

Compact leaderboard for embedding on your site, with profile links.

Params: period=1d|7d|30d|all

Try: /api/embed/leaderboard?period=all

Fields: rank, name, pnl, pfp, profile_url, platform, smart_score, win_rate, sharpe_ratio

GET/api/kalshi-leaderboard

Kalshi-only leaderboard of the top 1,000 Kalshi traders, tracked over time.

Params: period=1d|7d|30d|all, limit=1-2000 (default 1000)

Try: /api/kalshi-leaderboard?period=30d&limit=100

Fields: rank, kalshi_username, name, pfp, pnl, pnl_all, kalshi_url, profile_path, last_synced_at

GET/api/trader/{wallet-or-kalshi-username}

One trader's profile: P&L by period, wallets, linked accounts and smart score.

Try: /api/trader/ProbabilityDuck

Fields: name, platform, wallet, additional_wallets, kalshi_username, stats, smart_score, join_date, portfolio_value

GET/api/trader/{wallet}/positions

Live open Polymarket positions for a tracked trader, largest first.

Params: limit=1-500, offset, sizeThreshold

Try: /api/trader/0xec981ed70ae69c5cbcac08c1ba063e734f6bafcd/positions?limit=20

Fields: market, outcome, size, avg_price, current_price, current_value, cash_pnl, percent_pnl, polymarket_url, end_date

GET/api/trader/{wallet}/trades

Recent Polymarket trades for a tracked trader.

Params: limit=1-500, offset

Try: /api/trader/0xec981ed70ae69c5cbcac08c1ba063e734f6bafcd/trades?limit=20

Fields: time, market, type, outcome, amount, price, shares_amount, transaction_hash, polymarket_url

GET/api/kalshi/{username}/history

All-time P&L history for a Kalshi trader, from our snapshots.

Try: /api/kalshi/ProbabilityDuck/history

Fields: history[].timestamp, history[].pnl, history[].date, dataPoints, firstDate, lastDate

GET/api/kalshi/{username}/categories

A Kalshi trader's all-time P&L and markets traded by category.

Try: /api/kalshi/acedia/categories

Fields: categories[].category, categories[].pnl, categories[].markets

GET/api/p/overview

Open Polymarket positions across top traders, with each trader's score.

Try: /api/p/overview

Fields: market, outcome, size, current_value, cash_pnl, trader_name, trader_wallet, trader_score, polymarket_url

GET/api/m/insights

Markets top traders are trading most, with buy/sell and yes/no flow.

Params: period=1h|6h|24h|3d|1w, limit=1-200

Try: /api/m/insights?period=24h&limit=10

Fields: market, totalVolume, buyVolume, sellVolume, yesVolume, noVolume, netInflow, uniqueTraders, yesPrice, polymarket_url

GET/api/daily-profit

Combined profit of all tracked traders today.

Try: /api/daily-profit

Fields: daily_profit, raw, traders_count

GET/api/kalshi-avatar/{username}

A Kalshi trader's profile picture (128px WebP).

Try: /api/kalshi-avatar/4thewin

Returns an image.

GET/api/og/calendar/{wallet-or-kalshi-username}

Shareable month card (1080x1350): daily P&L tiles, win/loss record and monthly profit.

Params: month=YYYY-MM (default: current month)

Try: /api/og/calendar/ProbabilityDuck

Returns an image.

GET/api/og/trader/{wallet-or-kalshi-username}

Shareable 1200x630 P&L card image for a trader.

Try: /api/og/trader/ProbabilityDuck

Returns an image.

Rate limits

100 requests per minute per IP across the API (images excluded). Leaderboards allow 120/min, trader profiles 60/min per trader, positions and trades 120/min. Responses include X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset headers.
